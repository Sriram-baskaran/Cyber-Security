# SQL Injection (SQLi)

SQL Injection is a vulnerability that allows attackers to manipulate SQL queries executed by a backend database.

## Types of SQL Injection

- UNION-based SQL Injection
- Error-based SQL Injection
- Blind SQL Injection
- Time-based Blind SQL Injection
- Out-of-Band SQL Injection

- Identifying SQL injection points

- Determining column counts
- Finding text-compatible columns
- Retrieving database information
- Enumerating tables and columns
- Extracting sensitive data
- Blind SQL Injection
- Burp Suite Repeater
- Burp Suite Intruder
