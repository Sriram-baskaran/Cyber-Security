# Blind SQL Injection

Blind SQL Injection occurs when an application does not directly display database query results or SQL errors.

Instead, attackers infer information by observing differences in application behavior.

## Techniques

- Conditional Responses ✅
- Conditional Errors
- Time Delays
- Out-of-Band

## Learning Objectives

- Build boolean-based payloads
- Extract sensitive information without direct output
- Automate extraction using Burp Suite Intruder
- Understand inference-based attacks
